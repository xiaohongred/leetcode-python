# 回溯算法总结

## 一、回溯的基本套路

回溯算法的核心是：先把当前候选状态放入路径，再递归探索，最后在所有分支结束后通过 `pop()`、`path.clear()` 或其他状态恢复，保证后续分支不受前一分支影响。

常见代码模板：

```python
def backtrack(index):
    # 1. 递归终止条件：当前状态已经满足题目要求
    if index == n:
        result.append(path.copy())
        return

    # 2. 遍历当前层的所有候选项
    for choice in choices:
        # 3. 选择候选项并更新状态
        path.append(choice)
        used.add(choice)

        # 4. 继续递归
        backtrack(index + 1)

        # 5. 回滚状态，恢复到下一分支开始前
        path.pop()
        used.remove(choice)
```

### 常见状态管理

- `path`：当前构造的答案。
- `used`、`visited`：记录已使用或已访问的元素。
- `ans`：保存完整答案的结果集合。
- `path.copy()`：保存当前答案，避免后续回滚后被修改。
- `pop()`、`remove()`：撤销当前分支的状态。

### 递归终止条件

终止条件通常有三种：

1. 已经处理完所有输入元素；
2. 当前路径满足题目要求；
3. 当前状态已经无法继续，通常通过约束条件提前返回。

## 二、三种回溯类型

### 1. 子集型回溯

子集型回溯通常用于枚举每个元素是否被选中。每个元素都有“选中”和“不选中”两个分支。

适合问题：

- 所有子集；
- 组合满足某个条件的子集；
- 选择若干元素构造新集合。

核心模板：

```python
def dfs(i):
    if i == n:
        ans.append(path.copy())
        return

    dfs(i + 1)              # 不选当前元素
    path.append(nums[i])
    dfs(i + 1)              # 选当前元素
    path.pop()
```

当前文件中的 `subsets()` 使用了这一套路。

### 2. 组合型回溯

组合型回溯通常用于选择若干元素，但不要求排列顺序。通过从当前下标开始遍历，避免重复生成同一套组合。

适合问题：

- 所有非空子集；
- 组合长度为 k 的集合；
- 选择若干元素且不考虑顺序的集合。

核心模板：

```python
def dfs(start):
    ans.append(path.copy())

    for i in range(start, n):
        path.append(nums[i])
        dfs(i + 1)
        path.pop()
```

这里的 `i + 1` 是关键：它防止同一个元素被重复选中，并保证从当前元素之后开始选择，避免生成重复组合。

当前文件中的 `subsetsV2()` 使用了这一套路。

### 组合型回溯的剪枝

组合型回溯最常见的剪枝是「剩余可选数字不够用」时提前返回。

以「从 `1..n` 中选 `k` 个数字」为例，设：

- `d = k - len(path)`：还差几个数字；
- `i`：当前还能选择的最大数字，即可选范围是 `1..i`。

如果 `i < d`，说明剩下 `i` 个数字全选上也凑不满 `d` 个，这条分支必然无解，可以直接返回。

同一个约束也可以写进循环下界。假设这一层选择 `j`，那么剩下 `d - 1` 个数字只能从
`1..j-1` 中选，最多只能提供 `j - 1` 个，因此必须满足：

$$j - 1 \ge d - 1 \iff j \ge d$$

所以循环写成 `range(i, d - 1, -1)`，下界 `d` 就是剪枝本身。

两种写法的实测对比（`n = 4, k = 2`）：

| 写法 | 结果数量 | 是否正确 | 说明 |
| --- | --- | --- | --- |
| 下界取 `d` | 6 | ✅ | 递归调用最少，单独使用即可 |
| 下界取 `d - 1`，无剪枝 | 10 | ❌ | 多出 `[4, 0]`、`[3, 0]` 等非法组合 |
| 下界取 `d - 1` + 显式剪枝 | 6 | ✅ | 每层多一次立刻返回的无效调用 |

结论：`i < d` 与「循环下界 = `d`」是同一个约束的两种表达，至少要保留一个；
`d - 1` 只有在同时开启显式剪枝时才安全。

#### 带目标和的剪枝（LeetCode 216）

当题目除了「选几个数」还要求「和为多少」时，可以把剩余目标和 `t` 也纳入剪枝。
设还差 `d` 个数、可选数字范围是 `1..i`，则剩余和必须落在一个区间内：

- **下界剪枝**：最小的 `d` 个数是 `1, 2, ..., d`，所以必须 `t >= d(d+1)/2`；
- **上界剪枝**：最大的 `d` 个数是 `i, i-1, ..., i-d+1`，所以必须 `t <= d(2i-d+1)/2`；
- **符号剪枝**：数字全为正，所以必须有 `t >= 0`。

其中上界公式由等差数列求和得出：

$$S = \frac{d \times \big(i + (i - d + 1)\big)}{2} = \frac{d(2i - d + 1)}{2}$$

`LeetCode 216` 中写的是上界与符号剪枝：

```python
if t < 0 or t > (i * 2 - d + 1) * d // 2:
    return
```

还有一个值得注意的细节：**这个剪枝顺便完成了终点的合法性校验**。走到终点时
`d = 0`，上界公式退化为 `0`，于是 `t > 0` 和 `t < 0` 两个条件合起来等价于
「只接受 `t == 0`」，因此代码里不需要再单独判断 `t == 0`。

剪枝收益实测（dfs 调用次数，`1..9` 中选数）：

| 用例 | 不剪枝 | 只有上界剪枝 | 再加下界剪枝 |
| --- | --- | --- | --- |
| `k=3, n=7` | 28 | 26 | 11 |
| `k=3, n=9` | 50 | 46 | 22 |
| `k=4, n=20` | 178 | 102 | 89 |
| `k=5, n=25` | 214 | 116 | 96 |
| `k=7, n=35` | 109 | 61 | 46 |

### 3. 排列型回溯

排列型回溯通常需要考虑元素的顺序。每个位置都从候选项中选择，且通常需要使用 `used` 记录已选择的元素，防止重复使用。

适合问题：

- 所有排列；
- 具有顺序的答案；
- 生成所有可能的路径。

核心模板：

```python
def dfs(index):
    if index == n:
        ans.append("".join(path))
        return

    for choice in choices:
        if not used[choice]:
            path.append(choice)
            used[choice] = True
            dfs(index + 1)
            used[choice] = False
            path.pop()
```

排列型回溯与组合型回溯的主要区别是：组合只记录“选了哪些元素”，排列还要记录“元素以什么顺序出现”。

### 4. 位置型回溯：用「约束」驱动分支（LeetCode 22）

前面几类都是先枚举元素再判断合法性，而 LeetCode 22（生成括号）换个角度：
**按位置从左到右填空**，每个位置分别判断「能不能填当前这个字符」。

设 `i` 是下一个要填的位置、`open` 是已放左括号数，则已放右括号数就是 `i - open`：

- 能放 `(` 的条件：`open < n` —— 左括号总数只有 `n` 个（总数上限剪枝）；
- 能放 `)` 的条件：`i - open < open` —— 右括号数必须严格小于左括号数（前缀平衡剪枝）。

```python
if open < n:                 # 还能放 '('
    path[i] = '('
    dfs(i + 1, open + 1)
if i - open < open:          # 还能放 ')'
    path[i] = ')'
    dfs(i + 1, open)
```

这类写法和前面几种有明显区别：

- 约束写成**正向的「可以选」判断**，而不是提前 `return`；
- 两个 `if` 并列，同时成立时分叉，都不成立时该分支自然结束，相当于剪枝；
- 用固定长度数组 `path[i] = c` 覆盖写入时，**不需要 `pop()`**，因为读取只发生在填满之后。

剪枝效果（搜索节点数 vs 暴力枚举 $2^{2n}$）：

| n | 受约束搜索 | 全枚举 $2^{2n}$ | 倍数 |
| --- | --- | --- | --- |
| 5 | 196 | 1024 | 5.2x |
| 7 | 2055 | 16384 | 8.0x |
| 10 | 82499 | 1048576 | 12.7x |

结果总数等于卡塔兰数 $C_n = \dfrac{1}{n+1}\dbinom{2n}{n}$。

## 三、三种回溯的选择依据

| 类型 | 重点 | 主要约束 | 典型实现 |
| --- | --- | --- | --- |
| 子集型 | 每个元素是否选中 | 不考虑顺序 | 选择或不选择分支 |
| 组合型 | 选取若干元素的集合 | 不考虑顺序，避免重复 | 从当前下标开始遍历 |
| 排列型 | 选项出现的顺序 | 不能重复使用元素 | 位置递归与 `used` |
